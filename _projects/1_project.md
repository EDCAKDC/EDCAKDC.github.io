## Long-term CAR-T persistence

Reproducible computational analysis associated with the *Nature Medicine* study **Decade-long persistence of CD19 CAR T cells in B cell lymphomas**.

**My role:** computational analysis for the study.

The analysis integrates single-cell transcriptomics and immune-repertoire information to characterize long-term persisting CAR-T cells, including:

- CAR-positive versus CAR-negative state comparison
- peak versus year-9.3 longitudinal analysis
- differential expression and pathway analysis
- TCR clonotype dynamics
- regulatory-state analysis
- external reference comparison
